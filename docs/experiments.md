# 评测结果与消融设计

## 预实验与数据

用 Qwen3-VL-8B 在 Geometry3K validation 的 300 题做原图、去图和文本化图形条件对照。基座在原图与去图条件下的准确率分别为 55.33% 和 11.67%。个案发现数值读对但绑错线段、顶点角与圆心角混淆，以及在条件读取正确后发生的计算错误。主训练使用 Geo3K train 的 2,101 题，评测分开报告四个 benchmark。

## 4B 复评

| 方案 | Geo3K 601 | GeoQA 740 | MathVista testmini 1,000 | MathVision testmini 304 |
|---|---:|---:|---:|---:|
| Qwen3-VL-4B-Instruct | 56.68% | 67.43% | 74.63% | 31.14% |
| DAPO · step 120 | 71.99% | 69.46% | 77.00% | 44.96% |
| DAPO + 遮挡对照及配套 NLL · step 120 | **76.21%** | **74.23%** | **78.43%** | 44.74% |
| 差值（百分点） | +4.22 | +4.77 | +1.43 | −0.22 |

用同一处理器、题目、规则判分和三个共同解码种子 42、43、44，求准确率均值。回答上限 4096 tokens，temperature 0.7、top-p 0.8、top-k 20、presence penalty 1.5。两个 checkpoint 对应各自的一次训练，GPU 数存在差异。题目层面的配对 bootstrap 95% 区间分别是 Geo3K [+1.80, +6.63]、GeoQA [+2.75, +6.80]、MathVista [+0.10, +2.78]、MathVision [−3.73, +3.18]，未做多重比较校正。

Geo3K test 中 300/601 题与训练集精确同图，另 301 题的差值为 +2.44 个百分点，区间跨零。GeoQA 未发现精确同图。MathVista 有 32 道精确同图。历史测试划分用于训练期监控，后续确认实验需加入从未参与选参的新图像留出集。

32 张图上的 96 个事实探针，基座、DAPO、遮挡方案分别答对 92、93、91 道。样本难度偏低，参考由模型辅助核对。400 题高 attention 选区实验表明高关注区域比匹配随机区域更能影响预测，提供了后续选区研究的依据。任务相关选区的训练收益仍待验证。

## 消融设计

先在同一 4B GRPO 基线上匹配结构化提示、结果判分、clean NLL、训练数据、采样和评估预算，四组分别只打开需要比较的组件。

| 组别 | 遮挡差异项 | 证据奖励与感知 token 路由 |
|---|---|---|
| A | 关 | 关 |
| B | 开 | 关 |
| C | 关 | 开 |
| D | 开 | 开 |

`B − A` 衡量单独加入遮挡的增益，`C − A` 衡量单独加入解耦的增益，`D − C − B + A` 衡量两种信号的交互。对困难事实正确率、证据遗漏和最终答案分别测量。若继续归因，加入只启用证据奖励的对照以估计 token 路由的边际作用。多训练种子用于复核，额外的裁判调用、反事实前向和 GPU 时间单独计量。组合训练和该四组同口径对照尚未运行。
