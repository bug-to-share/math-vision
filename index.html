预实验与数据构建

对 300 道 Geometry3K 题比较原图、去图与文本化图形条件，逐题核查数字与线段、角度与实体的错绑。整理 2,101 道训练题，审计图像重叠，并构建 96 道视觉事实探针。难例体现出单独识别数字与正确绑定几何关系之间的差距。

图像遮挡目标与 veRL 实现

保留 DAPO 策略损失，用同一回答对照原图和随机遮图下的逐 token 概率。通过 veRL actor worker 与 FSDP2 engine 在更新前缓存旧策略的遮图 log-prob，验证梯度隔离、缓存版本和微批次对齐，完成双卡全参数训练。

感知与推理解耦

借鉴 MoCA，将原图回答中的视觉证据交给文本代理独立解题，另外验证原回答的最终答案。对答错轨迹，按证据是否足够调整 <recognition> token 的优势，减轻可靠证据在后续推导出错时受到的负向更新。

完成标准 GRPO 奖励与 token 路由实现及 CPU 验证。GPU 成绩与两项方法的交互实验待补。

评测与机制分析

统一复评 Geo3K、GeoQA、MathVista 和 MathVision 共 2,645 道题。几何题汇总分数提高，MathVision 变化为 −0.22 个百分点。简单事实探针尚未检出读图改善。后续用随机遮挡、解耦奖励和两项组合的训练对照，分别测量困难视觉事实和最终解题的变化。
